# E-Shopping Demo

### Android E-Commerce Application

A portfolio/project e-commerce demo application built with **Kotlin and Jetpack Compose**, designed to demonstrate modern Android development practices and a realistic shopping experience.

<br>

| MODULE               | IMPLEMENTATION               |
| :------------------- | :--------------------------- |
| Architecture         | MVVM                         |
| UI                   | Jetpack Compose + Material 3 |
| Dependency Injection | Hilt                         |
| Networking           | Retrofit                     |
| Product API          | DummyJSON                    |
| Authentication       | Firebase Authentication      |
| Database             | Cloud Firestore              |
| Image Loading        | Coil                         |
| Language             | Kotlin                       |

<br>

### Core Features

```text
PRODUCTS                  SHOPPING
────────────────────      ────────────────────
Product Listing           Add to Cart
Product Details           Remove from Cart
Product Images            Cart Management
Ratings & Reviews         Product Pagination


AUTHENTICATION             ACCOUNT
────────────────────      ────────────────────
Email Authentication      User Account
Firebase Auth             Authentication State
Login / Signup            Sign Out
```
